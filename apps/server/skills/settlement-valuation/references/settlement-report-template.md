# 结算计算书输出模板

本模板是 settlement-valuation 技能"阶段 B 第四步"的输出规范全文。输出结算计算书时严格按以下五段结构组织，每个数字都必须能在工具返回的凭证字段中溯源（flowId / extractionId / document_id）。

## 模板全文

```
结算计算书（合同 <contractNo>）

一、规则依据
    <条款摘要 1 条一行, 每条附 document_id>
    例: 质量奖罚条款——热值每偏差 100kcal 奖罚 X 元/吨（document_id: DOC-xxx）

二、数量依据
    <重量凭证清单: 单据类型 + 凭证日期 + flowId>
    结算数量 = <X> 吨（口径: executionProgress.delivered, 勿逐行累加流水）

三、质量依据
    <质检报告: extractionId, 各指标实际值 vs 合同基准值>

四、计算过程
    基准价 = <...> 元/吨（出处: 合同定价条款）
    <奖罚项 1> = (<实际值> - <基准值>) / <偏差单位> × <单位奖罚额> = ±<...> 元/吨
    <奖罚项 2> = ...
    结算单价 = 基准价 + Σ 调整额 = <...> 元/吨
    结算货值 = <X> 吨 × <...> 元/吨 = <...> 元

五、结论
    暂估 <...> 元 vs 结算 <...> 元, 差额 <...> 元
    （如有取舍口径, 在此说明理由）
```

## 使用要求

1. 五段顺序固定，缺证据的段落如实写"数据不可得"，不得留空或编造。
2. 计算过程分步展示，中间量不得跳步；奖罚有上下限的先截断再计算并注明。
3. 结论先完整展示给用户，用户明确确认后才调用 confirm_settlement。
